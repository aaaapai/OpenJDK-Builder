# OpenJDK-Builder

OpenJDK-Builder 只是一个简单的使用 Bash 脚本开发的 OpenJDK 自动化构建工具

## 特性

- 当前支持构建目标为 Android 和 iOS 平台的OpenJDK

## 目标系统

| 系统   | 支持情况   |
|--------|------------|
| Android| ✅ 支持     |
| iOS    | ✅ 支持     |
| 其它   | 🚧 计划中   |

## 目标JDK

| 版本   | 支持情况   |
|--------|------------|
| 27     | ✅ 支持     |
| 26     | 🚧 计划中   |
| 其它   | 🚧 计划中   |

| 供应商   | 支持情况   |
|--------|------------|
