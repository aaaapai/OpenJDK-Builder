# OpenJDK-Builder

OpenJDK-Builder用于构建OpenJDK

## 特性

- 当前支持构建目标为 Android 和 iOS 平台的OpenJDK

## 目标系统

| 系统   | 支持情况   |
|--------|------------|
| Android| ✅ 支持     |
| iOS    | 🚧 计划中     |
| 其它   | 🚧 计划中   |
