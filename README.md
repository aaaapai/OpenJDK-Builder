# OpenJDK-Builder

OpenJDK-Builder 只是一个简单的使用 Bash 脚本开发的 OpenJDK 自动化构建工具

## 特性

- 一键自动构建 OpenJDK
- 当前支持 Android 和 iOS 平台

## 系统兼容性

| 平台   | 支持情况   |
|--------|------------|
| Android| ✅ 支持     |
| iOS    | ✅ 支持     |
| 其它   | 🚧 计划中   |
